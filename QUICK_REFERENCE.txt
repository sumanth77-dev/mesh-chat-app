## Troubleshooting (Quick Fixes)

| Problem | Fix |
|---------|-----|
| No devices | Wait 45 sec, tap refresh |
| Connection fails | Move devices closer |
| Messages not sending | Reconnect device |
| App crashes | `flutter clean && flutter run` |
| Permissions error | Uninstall & reinstall app |

## Protocol

**Discovery**: Broadcast + BroadcastReceiver  
**Connection**: WifiP2pConfig + WPS  
**Messaging**: ServerSocket + Socket  
**Port**: 8888  
**Format**: Plain text + newline

## Common Customizations

### Change Port
```kotlin
// MainActivity.kt line ~322
serverSocket = ServerSocket(9999)  // Change 8888 to 9999
```

### Add Message Types
```dart
// chat_screen.dart - enhance ChatMessage class
class ChatMessage {
    String text;
    bool isMe;
    MessageType type;  // text, image, file, etc.
}
```

### Change UI Colors
```dart
// device_list_screen.dart
Colors.blue.shade700  // Change primary color
```
