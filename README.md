# mesh_chat_app

RelayX 🚀

RelayX is a decentralized offline communication platform that enables messaging without internet access using WiFi Direct and overlay mesh networking.

The application allows nearby devices to communicate through relay nodes, extending communication beyond direct device range. Messages can travel across multiple devices, making RelayX suitable for emergency communication, remote environments, and decentralized networking scenarios.

## ✨ Features

- 📡 WiFi Direct device discovery and peer connection
- 🔄 Multi-hop relay messaging through intermediate nodes
- 🌐 Overlay mesh networking architecture
- 🔐 End-to-end encrypted communication
- 💾 Local message storage using Hive database
- 🔔 Offline local notifications
- 📊 Real-time mesh network visualization graph
- 🚦 TTL (Time-To-Live) based packet forwarding
- 🛡 Duplicate packet detection and prevention
- 📦 Store-and-forward delivery for offline recipients
- 📨 Reliable delivery acknowledgements (ACK)
- 🔁 Automatic retry mechanism for undelivered messages
- ⚡ Real-time TCP socket communication
- 📱 Modern Flutter-based responsive UI
- 🔍 Connected device monitoring and management
- 📈 Live network topology visualization
- 🚑 Suitable for emergency and disaster communication
- 🌍 Internet-independent decentralized messaging
- 🔗 Dynamic peer announcement and discovery
- 🎯 Fault-tolerant relay-based communication system
- 🚀 Cross-platform development using Flutter
